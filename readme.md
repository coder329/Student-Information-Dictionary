# 👨‍🎓 Student Information Dictionary

## Task 7 - Level 1 - Day 7

A beginner-friendly Python project that uses a dictionary to store and manage student information.

The project demonstrates basic dictionary operations such as searching, adding, updating, and displaying student records.

---

## 📌 Project Overview

The Student Information Dictionary stores student records using unique Student IDs.

Each student record contains:

- Student ID
- Name
- Age
- Course
- Marks

The program performs the following operations:

- Search for a student
- Add a new student
- Update existing student information
- Display all student records
